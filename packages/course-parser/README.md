# course-parser

Turns the Markdown files written by the `course-builder` skill into Pydantic v2
models. Shared core between the local FastAPI server and, later, the SaaS
backend. The Markdown vault is the single source of truth: this package only
reads it.

## What it parses

| File | Function | Model |
| --- | --- | --- |
| `00-curriculum.md` | `parse_curriculum(text)` | `Course` (modules → topics with `topic-meta` → subtopics) |
| `lessons/<topic-id>-<slug>.md` | `parse_lesson(text)` | `Lesson` |
| `exercises/<topic-id>-<slug>.md` | `parse_exercise_set(text)` | `ExerciseSet` |
| `exercises/<topic-id>-attempt-<n>.md` | `parse_attempt(text)` | `Attempt` |

`parse_exercise_file(text)` dispatches between set and attempt using the
`attempt` front matter field. `load_course(course_dir)` bundles everything for
one course into a `CourseBundle`; `load_vault(root)` does the same for every
course folder under a courses root.

## CLI

```sh
# one course
uv run course-parser path/to/vault/java-para-quem-programa

# every course under a root, single-line JSON
uv run course-parser --compact path/to/vault
```

Output is JSON on stdout (dates as ISO strings). Parse errors go to stderr
with the offending file path and a non-zero exit code.

## Development

```sh
uv run pytest                       # from the repo root
uv run ruff check packages/course-parser
uv run ruff format packages/course-parser
```

Fixtures under `tests/fixtures/` are real courses generated by the skill and
double as the spec the parser must keep accepting.
